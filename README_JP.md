## 2.4.2 の変更点

- テンプレートと前処理結果をキャッシュし、複数状態の確認で同じフレームを共有します。通常ポーリング、クリック後待機、一覧スクロールも短縮しました。
- Link Raid は参加人数が `9/10`、`10/10`、または人数を確実に判定できない backup requests をスキップします。満員または終了済みの部屋は閉じて再検索します。
- `tap_to_countinue_1/2` を局所適応型の文字輪郭で認識し、720p、1080p、2K、4K に対応します。3フレーム確認ごとに画面下中央の安全位置を最大2回クリックします。
- 固定座標アクションは現在画面を実際に認識してクリックした後だけ `back` を受け入れ、戦闘画面の誤検出でいいね処理へ進むことを防ぎます。
- いいね一覧をスクロールした後はポインターを退避し、画面の安定を待って3秒間再認識します。最大9回の制限は維持されます。

## ダウンロードと起動

1. [GitHub Releases](https://github.com/LUODIAN-233/Magia_Exedra_auto/releases) から最新の Windows ZIP をダウンロードします。
2. ZIP を通常のフォルダーへ**すべて展開**します。
3. ルートにある `Magia_Exedra_auto.exe` を実行します。

> [!IMPORTANT]
> EXE だけをコピーしないでください。同じ場所に `_internal/`、`resource/`、`language/`、`tools/` が必要です。

## 周回モード

| モード | 開始前の画面 | 設定 | 自動処理 |
|:-------|:-------------|:-----|:---------|
| **Link Raid** | メイン／灯台画面 | LV4 または LV6-LV12、体力薬の回数 | backup requests、更新、指定レベルの選択、戦闘参加、結果整理、いいね |
| **Crystalis** | ステージと編成を選択し、`play` で戦闘が始まる画面 | 体力薬の回数 | 戦闘開始、結果待ち、`retry`、周回継続 |

対象を認識できない、待機がタイムアウトする、または体力薬の設定回数を使い切ると安全に停止します。Link Raid は選択したレベルがない場合でも別のレベルへ参加しません。

## 初回利用

1. ゲームをウィンドウモードで起動し、画面全体が見える状態にします。
2. 本ツールを起動し、テンプレート一覧の更新完了を待ちます。ゲーム言語を選択すると、解像度はクライアント領域から自動判定されます。
3. `挂机模式`（周回モード）を選び、設定後に `启动挂机`（開始）をクリックします。

実行中にキーボードやマウスを操作すると自動化は一時停止し、5秒間操作がなければ再開します。`停止挂机` で現在のタスクを終了できます。

> [!NOTE]
> テンプレート状態にゲーム未検出と表示された場合は、ゲームの起動完了とウィンドウタイトル `MadokaExedra` を確認してください。

## 主な設定

| 設定 | 動作 |
|:-----|:-----|
| ゲーム言語 | 英語と日本語に対応し、最後の選択を記憶します |
| 解像度 | `720p` / `1080p` / `2K` / `4K` テンプレートを自動選択します |
| ログレベル | 新規インストールは `INFO`。GUI のデバッグ記録と `logs/` のファイルを同時に制御します |
| ログ保持 | デフォルト7日、1～365日に変更可能。起動時または手動でクリーンアップします |
| beta 更新 | プレリリース版は beta チャネルがデフォルトで有効です。`设置` で変更できます |

## 使用前の注意

- Windows x86-64 / AMD64 のウィンドウモードのみ対応します。
- ゲームを表示したままにし、認識領域を他のウィンドウで隠さないでください。
- 本ツールはゲームをアクティブ化し、グローバルマウスを使用します。開始画面を確認してから実行してください。
- 認識はゲーム言語、ウィンドウサイズ、DPI、テンプレート品質の影響を受けます。
- 本ツールは学習・交流目的です。ゲームの利用規約を守り、自己責任で使用してください。

## トラブルシューティング

| 症状 | 最初に確認すること |
|:-----|:-------------------|
| ゲームを検出しない | ゲームが起動済みで、ウィンドウタイトルが `MadokaExedra` になっているか |
| テンプレートが `（空）` | 起動時更新の完了を待つか、`刷新列表` で再生成する |
| 自動化を開始できない | ゲーム言語、解像度、開始画面、必須テンプレートが一致しているか |
| 誤認識または誤クリック | 画面を隠さず、`DEBUG` を選んで再現し、`logs/` を確認する |
