## 2.5.0 の変更点

- Link Raid で複数レベルを選択し、ユーザーが設定した優先順位で部屋を検索できます。9/10 と 10/10 は個別にスキップを設定でき、参加人数を読み取れない部屋は参加を試みます。
- 自動周回モードと各モードの全パラメータを変更時に保存し、次回起動時に復元します。Link Raid から不要になった「いいね」操作を削除しました。
- Server酱 の重大イベント通知を追加し、専用 SendKey、1～2個の配信チャネル、イベントごとの設定に対応しました。バックグラウンド送信は再試行と重複排除を行い、手動停止やアプリ終了では自動終了通知を送信しません。

## ダウンロードと起動

1. [GitHub Releases](https://github.com/LUODIAN-233/Magia_Exedra_auto/releases) から最新の Windows ZIP をダウンロードします。
2. ZIP を通常のフォルダーへ**すべて展開**します。
3. ルートにある `Magia_Exedra_auto.exe` を実行します。

> [!IMPORTANT]
> EXE だけをコピーしないでください。同じ場所に `_internal/`、`resource/`、`language/`、`tools/` が必要です。

## 周回モード

| モード | 開始前の画面 | 設定 | 自動処理 |
|:-------|:-------------|:-----|:---------|
| **Link Raid** | メイン／灯台画面 | 複数レベルと優先順位、9/10・10/10 の個別ルール、体力薬の回数 | backup requests、更新、優先順位に沿ったレベル選択、戦闘参加、結果整理 |
| **Crystalis** | ステージと編成を選択し、`play` で戦闘が始まる画面 | 体力薬の回数 | 戦闘開始、結果待ち、`retry`、周回継続 |

対象を認識できない、待機がタイムアウトする、または体力薬の設定回数を使い切ると安全に停止します。Link Raid は LV4 と LV6-LV12 を同時に選択できます。最優先レベルに参加可能な部屋がなければ次の選択済みレベルを直ちに試し、未選択レベルには参加しません。参加人数を読み取れない場合は参加を試み、9/10 と 10/10 は個別にスキップまたは許可できます。

## 初回利用

1. ゲームをウィンドウモードで起動し、画面全体が見える状態にします。
2. 本ツールを起動し、テンプレート一覧の更新完了を待ちます。ゲーム言語を選択すると、解像度はクライアント領域から自動判定されます。
3. `挂机模式`（周回モード）を選び、設定後に `启动挂机`（開始）をクリックします。選択モードと各モードの全パラメータは変更時に直ちに保存され、次回起動時に復元されます。

実行中にキーボードやマウスを操作すると自動化は一時停止し、5秒間操作がなければ再開します。`停止挂机` で現在のタスクを終了できます。

> [!NOTE]
> テンプレート状態にゲーム未検出と表示された場合は、ゲームの起動完了とウィンドウタイトル `MadokaExedra` を確認してください。

## 主な設定

| 設定 | 動作 |
|:-----|:-----|
| ゲーム言語 | 英語と日本語に対応し、最後の選択を記憶します |
| 解像度 | `720p` / `1080p` / `2K` / `4K` テンプレートを自動選択します |
| 周回パラメータ | モードごとに全設定を記憶します。Link Raid の初期値は LV6 のみで、9/10 と 10/10 は両方スキップします |
| ログレベル | 新規インストールは `INFO`。GUI のデバッグ記録と `logs/` のファイルを同時に制御します |
| ログ保持 | デフォルト7日、1～365日に変更可能。起動時または手動でクリーンアップします |
| beta 更新 | プレリリース版は beta チャネルがデフォルトで有効です。`设置` で変更できます |
| Server酱 通知 | デフォルトは無効。マスク表示の SendKey、1～2個の配信チャネル、重大イベントを設定し、ローカルの `settings.json` に保存します |

Server酱 は WeChat サービス号／テスト号、WeCom アプリ通知、WeCom・DingTalk・Feishu グループ Bot、Bark、PushDeer、公式 Android クライアント、カスタム Webhook に対応し、1～2個のチャネルを選択できます。送信はバックグラウンドで行い、同一イベントは10分間重複排除し、失敗時は最大3回再試行します。スクリプトの自動終了は独立イベントですが、手動停止やアプリ終了では送信せず、LP 枯渇・タイムアウト・異常終了時にも自動終了通知を重複送信しません。SendKey はログに記録しません。

初回設定では、ログイン、購読／支払い、専用 SendKey、料金の受取先を説明する中国語の [Server酱 通知設定ガイド](./README_SERVERCHAN.md) を参照してください。

## 使用前の注意

- Windows x86-64 / AMD64 のウィンドウモードのみ対応します。
- ゲームを表示したままにし、認識領域を他のウィンドウで隠さないでください。
- 本ツールはゲームをアクティブ化し、グローバルマウスを使用します。開始画面を確認してから実行してください。
- 認識はゲーム言語、ウィンドウサイズ、DPI、テンプレート品質の影響を受けます。
- 本ツールは学習・交流目的です。ゲームの利用規約を守り、自己責任で使用してください。

## トラブルシューティング

| 症状 | 最初に確認すること |
|:-----|:-------------------|
| ゲームを検出しない | ゲームが起動済みで、ウィンドウタイトルが `MadokaExedra` になっているか |
| テンプレートが `（空）` | 起動時更新の完了を待つか、`刷新列表` で再生成する |
| 自動化を開始できない | ゲーム言語、解像度、開始画面、必須テンプレートが一致しているか |
| 誤認識または誤クリック | 画面を隠さず、`DEBUG` を選んで再現し、`logs/` を確認する |

詳しい手順、認識保護、問題解決は [Wiki · ユーザーガイド](https://github.com/LUODIAN-233/Magia_Exedra_auto/wiki/ユーザーガイド) を参照してください。
