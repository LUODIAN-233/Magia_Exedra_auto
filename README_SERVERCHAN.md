# Server酱 通知配置指南

本项目可以通过 [Server酱Turbo](https://sct.ftqq.com/) 将脚本自动结束、体力耗尽、识图超时等重大事件推送到微信、Bark 等设备。Server酱 是独立的第三方推送服务，本项目只使用其官方 API 发送通知。

Server酱官方将推送凭证称为 **SendKey**。它就是本项目需求中所说的应用专用 AppKey；本项目仅支持以 `SCT` 开头的 Server酱Turbo SendKey，不支持以 `sctp` 开头的 Server酱³ SendKey。

## 登录 Server酱

1. 打开 [Server酱Turbo 官网](https://sct.ftqq.com/)。
2. 点击右上角「登入」，使用微信扫码登录。
3. 后续配置通道或订阅时，请始终使用同一个微信账号。

根据 [Server酱官方 SendKey 文档](https://sct.ftqq.com/docs/getting-started/sendkey/)，新注册用户目前可获得免费额度和 7 天全功能试用。实际额度、试用期和服务规则以后可能调整，请以官网当前页面为准。

## 充值或购买订阅

1. 登录后进入 [Server酱「订阅」页面](https://sct.ftqq.com/subscribe)。
`2. 先使用免费额度和试用期完成推送测试，再决定是否购买订阅；官网当前明确提示订阅不支持退款。`
3. 在 Server酱页面选择套餐，核对价格、期限、退款规则和收款方后，再由用户自行扫码付款。
4. 充值时使用与登录 Server酱相同的微信账号，否则会员时间可能进入另一个账号。

> **费用说明：所有充值、订阅及相关服务费用均由 Server酱服务方收取。本项目及项目作者不收取、不代收、不分成，也无法处理账单、退款或发票问题。价格和售后规则以 Server酱付款页面及官方说明为准。**

## 准备本应用专用 SendKey

1. 登录 Server酱后进入 [「Key&API」页面](https://sct.ftqq.com/sendkey)。
2. 如果页面支持新增或备注多个 SendKey，请为本项目单独创建一个，并备注为 `Magia Exedra Auto`。
3. 如果当前账号只显示一个 SendKey，可将该密钥专门用于本项目；若它已被其他程序使用，重置前先确认不会导致其他推送失效。
4. 确认密钥以 `SCT` 开头后复制备用。不要把它发送给他人，也不要写入截图、日志、Issue 或公开文档。

SendKey 等同于推送权限。若怀疑泄露，请立即在 Server酱控制台重置，并在本项目中更新配置。

## 在本项目中启用

1. 启动本项目，点击「设置」。
2. 在「通知设置」中填写刚准备的 SendKey。
3. 选择 1-2 个已经在 Server酱「通道配置」中绑定好的通道。
4. 选择需要推送的重大事件，再勾选「启用 Server酱 通知」。
5. 点击「发送测试通知」，确认设置窗口显示成功且设备收到消息。

脚本自动结束可以单独推送；点击「停止挂机」或关闭程序不会推送。若同一次运行已经因为体力耗尽、超时或异常退出发送重大事件，也不会再重复发送自动结束通知。

本项目会把 SendKey 明文保存在本机且被 Git 忽略的 `settings.json` 中，输入框默认遮蔽；密钥不会写入 GUI 日志或文件日志。

## 常见问题

- **测试按钮不可用：** 检查 SendKey 是否以 `SCT` 开头，并确认至少选择了一个通道。
- **第三个通道无法勾选：** 本项目限制每次最多选择两个推送通道。
- **显示发送成功但设备没有收到：** 前往 Server酱「通道配置」确认对应通道已经绑定，再查看「推送日志」。
- **发送失败：** 检查网络、Server酱额度、订阅状态和 SendKey 是否有效；本项目会在后台最多重试 3 次。

更多说明请查看 [Server酱官方文档](https://sct.ftqq.com/docs/)、[SendKey 获取说明](https://sct.ftqq.com/docs/getting-started/sendkey/) 和 [通道对比](https://sct.ftqq.com/docs/getting-started/channels/)。
