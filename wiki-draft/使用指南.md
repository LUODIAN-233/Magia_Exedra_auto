# 使用指南

语言：[简体中文](./首页) · [English](./Home_EN) · [日本語](./ホーム)

本页面向直接使用 Windows 发行包的用户。源码安装、打包和开发说明请转到 [源码运行与构建](./源码运行与构建) 和 [开发约定](./开发约定)。

## 安装

1. 从 [GitHub Releases](https://github.com/LUODIAN-233/Magia_Exedra_auto/releases) 下载 Windows ZIP。
2. 完整解压 ZIP，不要只复制 `Magia_Exedra_auto.exe`。
3. 确认 EXE 同级存在 `_internal/`、`resource/`、`language/` 和 `tools/`。
4. 运行 `Magia_Exedra_auto.exe`。

发行版不会打开额外的控制台窗口。运行消息显示在 GUI 中，文件日志位于程序根目录的 `logs/`。

## 通用准备

- 仅支持 Windows x86-64 / AMD64 的窗口模式游戏。
- 游戏窗口标题必须为 `MadokaExedra`。
- 游戏必须保持可见，不能被其它窗口遮挡识图区域。
- 先选择正确的游戏语言，再选择挂机模式和参数。
- 启动时程序会刷新模板列表；首次生成多分辨率模板可能需要等待。
- 分辨率按游戏客户区自动选择，无需手动指定。

模板状态显示未检测到游戏时仍可调整语言，但开始挂机前必须先启动游戏。未知分辨率、对应模板不可用或必需模板缺失时，程序会阻止任务启动。

## Link Raid

### 起始界面

让游戏停留在主界面（灯台界面），不要提前进入求援列表。

### 参数

- 等级：LV4 或 LV6-LV12。
- 体力药：GUI 显示实际允许使用的次数；次数耗尽后停止。

### 流程

1. 进入任务与 Link Raid。
2. 打开求援列表并清理已结束战斗。
3. 刷新列表，寻找所选等级。
4. 加入战斗并等待结算。
5. 在正常结算或清理已结束战斗时处理可用点赞。
6. 返回求援列表继续循环。

所选等级不存在或无法安全点击时会刷新并重新搜索，不会加入其它等级。等级识别会在同一候选位置比较全部支持等级，并独立比较中央等级数字区域；只有整图与数字区域都把所选等级判为最佳候选时才点击。

点赞流程只会在成功点击 `tap_to_countinue` 后执行。点击 `joined_battles` 本身不会触发点赞。

## 晶花

### 起始界面

先选择关卡和队伍，停留在点击 `play` 就会开始战斗的界面。

### 参数

- 体力药：GUI 显示实际允许使用的次数；次数耗尽后停止。

### 流程

1. 点击 `play` 开始战斗。
2. 等待结算页并点击 `result`。
3. 点击 `retry` 开始下一轮。
4. 体力不足时按设置尝试恢复，否则停止。

晶花 `result` 只在游戏客户区右侧 50% 搜索；其逐图片阈值在 `resource/template_confidence.txt` 中默认设为 0.85，以排除左侧静态画面的误匹配。

## 模板与分辨率

- 语言支持 `EN` 与 `JP`，程序会记住最后选择。
- 启动任务时会根据客户区自动选择 `720p`、`1080p`、`2K` 或 `4K` 模板。
- `（空）` 表示该模板包不可用；可等待启动刷新完成或点击「刷新列表」。
- 2K 是原始模板，720p、1080p 和 4K 由程序增量生成。
- JP 服务器也可在游戏内切换到 EN 后使用英语模板。
- 每张逻辑 PNG 的匹配阈值由 `resource/template_confidence.txt` 单独控制，保存后下一次识图自动生效；缺项或格式错误会阻止挂机启动。

模板制作者需要了解的文件命名、`aim` 联接、缩放配方和完整性校验见 [模板包与分辨率](./模板包与分辨率)。

## 识别与防误点击

- 模板识别只截取游戏客户区，不包括标题栏和窗口边框。
- 同一模板组的全部编号变体使用同一帧比较，只采用得分最高的候选。
- 模板点击前会在 0.6 秒内采样三次；三次均超过阈值且中心位置相近才点击。
- 普通界面等待超过 60 秒、战斗等待超过 30 分钟时会安全停止。
- 检测到键盘输入或大幅移动鼠标时会暂停，连续 5 秒无用户操作后恢复。
- 等待可点击模板时，每连续 5 秒未匹配就观察游戏客户区 2 秒。画面变化超过 50% 时按战斗动画处理并跳过恢复点击；画面稳定时才可能在上一次安全操作位置执行一次恢复点击。
- 已声明下一步页面的流程，只有识别到下一步才确认点击成功；当前页面仍存在时可能冗余点击一次并继续等待。

这些策略能降低单帧相似画面和窗口装饰造成的误点击，但不能在游戏被遮挡、模板语言错误或窗口尺寸异常时保证识别正确。

## 设置与记忆

| 设置 | 行为 |
|:-----|:-----|
| 挂机模式 | 记住最后选择并在下次启动恢复 |
| 游戏语言 | 记住最后选择；实际 `aim` 目标仍是当前模板来源 |
| 日志等级 | 默认 `INFO`，同时控制 GUI 调试记录与文件日志 |
| 日志保留 | 默认 7 天，可设置 1-365 天；启动时自动清理过期日志 |
| 更新至 beta 版 | beta 版本默认勾选；取消后只检查 stable 版本 |

「清理过时日志」会按当前保留天数立即执行，当前会话正在使用的日志及轮转文件始终保留。

## 日志等级

| 等级 | 建议用途 |
|:-----|:---------|
| `INFO` | 日常使用，记录完整挂机流程 |
| `DEBUG` | 复现识别问题，额外记录模板分数和识图细节 |
| `WARNING` | 只保留警告、错误和严重错误 |
| `ERROR` | 只保留错误和严重错误 |
| `CRITICAL` | 只保留严重错误 |

挂机运行消息在 GUI 中始终显示为 INFO。INFO/DEBUG 会把这些流程消息写入文件；WARNING 及以上在没有对应异常时可能产生空日志。

## 故障排查

### 未检测到游戏

1. 确认游戏已完成启动。
2. 确认窗口标题为 `MadokaExedra`。
3. 确认游戏不是最小化状态。
4. 重新启动工具，让模板状态在启动时再次检测。

### 模板显示为空

1. 等待首次启动的模板缩放完成。
2. 点击「刷新列表」。
3. 确认完整解压了 `language/` 和 `tools/`。
4. 确认安全软件没有隔离 `tools/ImageMagick/magick.exe`。

### 分辨率不匹配

使用受支持的 16:9 窗口分辨率，并避免极端 DPI/窗口缩放。程序允许一定尺寸误差，但未知或明显不匹配的客户区会阻止启动。

### 识别不到或误点击

1. 保持游戏完全可见且无遮挡。
2. 确认游戏语言和模板语言一致。
3. 确认从正确起始界面启动模式。
4. 将日志等级切到 `DEBUG`，复现一次后停止。
5. 保留最新的 `logs/magia_*.log`，并说明游戏语言、客户区分辨率、模式和发生步骤。

### 日志文件为空

确认日志等级。`WARNING`、`ERROR` 或 `CRITICAL` 在没有对应问题时允许为空；日常流程记录应使用 `INFO`。
