# ユーザーガイド

言語：[简体中文](./首页) · [English](./Home_EN) · [日本語](./ホーム)

このページは Windows リリースパッケージを直接使用する方向けです。ソース実行、パッケージ化、開発については [ソース実行とビルド](./ソース実行とビルド) と [開発規約](./開発規約) を参照してください。

## インストール

1. [GitHub Releases](https://github.com/LUODIAN-233/Magia_Exedra_auto/releases) から Windows ZIP をダウンロードします。
2. ZIP をすべて展開し、`Magia_Exedra_auto.exe` だけをコピーしないでください。
3. EXE と同じ場所に `_internal/`、`resource/`、`language/`、`tools/` があることを確認します。
4. `Magia_Exedra_auto.exe` を実行します。

リリース版は追加のコンソールを開きません。実行メッセージは GUI に表示され、ファイルログはプログラムルートの `logs/` に保存されます。

## 共通の準備

- Windows x86-64 / AMD64 のウィンドウモードのみ対応します。
- ゲームウィンドウのタイトルは `MadokaExedra` である必要があります。
- ゲームを表示したままにし、認識領域を他のウィンドウで隠さないでください。
- 正しいゲーム言語を選んでから、モードと設定を選択します。
- EXE 起動時は更新チェック後にテンプレート一覧を更新します。初回の複数解像度生成には時間がかかる場合があります。
- 解像度はゲームのクライアント領域から自動選択されます。

テンプレート状態がゲーム未検出でも言語は変更できますが、自動化を開始する前にゲームを起動してください。未知の解像度、利用できない pack、必須テンプレート不足は開始をブロックします。

## Link Raid

### 開始画面

ゲームをメイン／灯台画面に置きます。backup requests へ先に移動しないでください。

### 設定

- レベル：LV4 または LV6-LV12。
- 体力薬：GUI に実際の許可回数が表示され、使い切ると停止します。

### 処理

1. quests と Link Raid を開きます。
2. backup requests を開き、終了済み戦闘を整理します。
3. 一覧を更新し、選択レベルを検索します。
4. 戦闘へ参加して結果を待ちます。
5. 通常結果または終了済み戦闘の整理後に利用可能ないいねを処理します。
6. backup requests に戻って繰り返します。

選択したレベルがない、または安全にクリックできない場合は更新して再検索し、別のレベルには参加しません。同じ候補位置で全対応レベルを比較し、中央のレベル数字領域も独立して採点します。両方が選択レベルを最良候補と判定した場合だけクリックします。最初の検索でレベルも `no_lv` も見つからない場合は、もう一度検索してから下方向へのスクロールを最大1回だけ行い、最後に再検索します。更新ボタンを実際にクリックしてから次の自動入力まで最低4.5秒を確保し、その間の認識と処理時間も含めます。参加人数が `9/10`、`10/10`、または確実に読み取れない候補は安全にスキップします。満員または終了済みの部屋は閉じて再検索します。

`play` の後は、戦闘待機中に遅れて表示される `already_end` と通常の結果状態を同時に確認します。中央のダイアログ領域で完全なメッセージと対応する `OK` が3フレーム連続して同時に一致した場合だけ1回クリックして再検索し、1フレームだけの誤検出や消えたダイアログから別画面の汎用 `OK` をクリックすることはありません。結果画面は `tap_to_countinue_1/2` の局所適応型文字輪郭だけで確認し、メダル画像には依存せず、動的背景も照合から除外します。各クリックには3フレーム確認が必要で、1回目で進まず文字が残る場合だけ、もう1回までクリックします。少なくとも1回の確認済みクリック後にだけ `back` を受け入れていいね処理を開始します。いいね一覧のスクロール後はポインターを退避し、画面の安定を待って3秒間再認識します。`joined_battles` のクリック自体では開始しません。

## Crystalis

### 開始画面

ステージと編成を選び、`play` をクリックすると戦闘が始まる画面で待機します。

### 設定

- 体力薬：GUI に実際の許可回数が表示され、使い切ると停止します。

### 処理

1. `play` で戦闘を開始します。
2. 結果を待ち、`result` をクリックします。
3. `retry` で次の周回を始めます。
4. 設定に従って体力を回復し、回復できなければ停止します。

Crystalis の `result` はゲームクライアント右側50%だけを検索します。`resource/template_confidence.txt` の画像別しきい値はデフォルト 0.85 で、左側の無関係な画面との誤一致を排除します。

## テンプレートと解像度

- `EN` と `JP` に対応し、最後の言語を記憶します。
- タスク開始時にクライアントサイズから `720p`、`1080p`、`2K`、`4K` を選択します。
- `（空）` は pack が利用できない状態です。起動時更新を待つか `刷新列表` をクリックします。
- 2K が原本で、720p、1080p、4K は差分生成されます。
- JP サーバーはゲーム内で EN に切り替えて英語テンプレートを再利用できます。
- 各論理 PNG のしきい値は `resource/template_confidence.txt` で個別に管理します。保存後は次回の認識から反映され、欠落や不正形式はタスク開始をブロックします。

ファイル命名、`aim` ジャンクション、スケーリング配方、整合性検証は [テンプレート pack と解像度](./テンプレートpackと解像度) を参照してください。

## 認識と誤クリック防止

- 認識はタイトルバーと境界を除くゲームクライアント領域だけを取得します。
- テンプレートグループの全番号候補を同一フレームで比較し、最高スコアだけを使用します。
- クリック前に0.6秒間で3回サンプリングし、すべてがしきい値を超え、中心位置が近い場合だけクリックします。
- `tap_to_countinue` は固定座標アクションです。`_1/2` の文字輪郭を3回認識した後、画面下中央の安全位置をクリックします。画面が残り、再び3フレーム確認に成功した場合だけ、2回目を1回まで許可します。検出テンプレート自体の位置は使わず、最初の確認済みクリック前に次画面テンプレートも受け入れません。
- 通常画面は60秒、戦闘待機は30分でタイムアウトします。
- キーボード入力または大きなマウス移動で一時停止し、5秒間操作がなければ再開します。
- クリック可能なテンプレートを5秒間認識できないと、クライアント領域を2秒観察します。50%を超える画素変化は戦闘アニメーションとして復旧クリックを行いません。安定画面では次画面を再確認し、まだ進んでいない場合だけ直前の安全位置へ復旧クリックすることがあります。
- 次画面が宣言された処理は、次画面を認識して初めて成功です。現在画面が残る場合は冗長クリックして待機を続ける場合があります。

これらは1フレームだけの類似画面やウィンドウ装飾による誤クリックを減らしますが、ゲームが隠れている、言語が違う、ウィンドウサイズが異常な場合の正しい認識を保証するものではありません。

## 設定と記憶

| 設定 | 動作 |
|:-----|:-----|
| 周回モード | 最後の選択を次回起動時に復元します |
| ゲーム言語 | 最後の選択を記憶し、実際の `aim` ターゲットを使用します |
| ログレベル | デフォルト `INFO`。GUI デバッグ記録とファイルログを制御します |
| ログ保持 | デフォルト7日、1～365日。起動時に期限切れログを削除します |
| `更新至 beta 版` | beta ビルドではデフォルト選択。解除すると stable のみ確認します |

`清理过时日志` は現在の保持日数ですぐに削除を実行します。現在のセッションログとそのローテーションは常に保持されます。

## ログレベル

| レベル | 推奨用途 |
|:-------|:---------|
| `INFO` | 通常利用と完全な自動化フロー |
| `DEBUG` | テンプレートスコアと認識詳細を含む問題再現 |
| `WARNING` | 警告、エラー、重大エラーのみ |
| `ERROR` | エラーと重大エラーのみ |
| `CRITICAL` | 重大エラーのみ |

自動化メッセージは GUI に INFO として常に表示されます。INFO/DEBUG はファイルにも記録し、WARNING 以上は該当イベントがない場合に空ファイルになることがあります。

## トラブルシューティング

### ゲームを検出しない

1. ゲームの起動が完了していることを確認します。
2. ウィンドウタイトルが `MadokaExedra` であることを確認します。
3. ゲームが最小化されていないことを確認します。
4. ツールを再起動して起動時検出を再実行します。

### テンプレートが空

1. 初回のテンプレートスケーリング完了を待ちます。
2. `刷新列表` をクリックします。
3. `language/` と `tools/` が完全に展開されているか確認します。
4. セキュリティソフトが `tools/ImageMagick/magick.exe` を隔離していないか確認します。

### 解像度不一致

対応する16:9ウィンドウ解像度を使用し、極端な DPI／ウィンドウスケーリングを避けてください。一定の誤差は許容しますが、未知または明確に異なるクライアントサイズは開始をブロックします。

### 認識しない、または誤クリック

1. ゲーム全体を表示し、隠さないでください。
2. ゲーム言語とテンプレート言語を一致させます。
3. 必要な開始画面からモードを開始します。
4. `DEBUG` を選び、1回再現して停止します。
5. 最新の `logs/magia_*.log` と、ゲーム言語、クライアント解像度、モード、発生手順を保存します。

### ログファイルが空

選択レベルを確認してください。`WARNING`、`ERROR`、`CRITICAL` は該当イベントがなければ空でも正常です。通常フローには `INFO` を使用します。
